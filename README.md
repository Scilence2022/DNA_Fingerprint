# DNA_Fingerprint

A DNA fingerprinting toolkit for generating and comparing genomic fingerprints from DNA sequence data.

## Components

### 1. Fingerprint Generator (fgr.c / fgr2.c)

The fingerprint generator creates a compact representation of DNA sequence files by selecting k-mers with the smallest hash values. This approach provides a consistent subsample of k-mers that can be used for similarity comparisons between different sequences.

#### Key Features:
- Fast k-mer counting with multi-threading support
- Configurable k-mer size (default: 31)
- Choice of hash functions (MurmurHash3 or Wang's hash)
- Coverage cutoff option to filter out low-frequency k-mers
- Outputs fingerprints with k-mer sequences, hash values, and counts

#### Usage:
```
./fgr [OPTIONS] <sequence_file>

Options:
  -k <int>        K-mer size (default: 31)
  -t <int>        Number of threads (default: 1)
  -o <file>       Output file for all k-mer counts
  -F <file>       Output file for top N k-mers with smallest hash values
  -N <int>        Number of top k-mers to include in fingerprint (default: 10000)
  -c <int>        Coverage cutoff for k-mers (default: 0)
  -w              Use Wang's hash function (default: MurmurHash3)
  -h              Display help message and exit
```

### 2. Similarity Calculator (calculate_similarity.py)

This Python script calculates similarity metrics between fingerprint files (.fgr) generated by the fingerprint generator, providing both Jaccard Index and Cosine Similarity measurements.

#### Key Features:
- Computes Jaccard Index between k-mer sets
- Calculates Cosine Similarity using k-mer coverage values
- Generates similarity matrices for multiple comparisons
- Optional dendrogram visualization of relationships (requires scipy and matplotlib)

#### Usage:
```
python calculate_similarity.py [OPTIONS] [directory]

Options:
  directory              Directory containing .fgr files (default: current directory)
  -o, --output_prefix    Output prefix for similarity matrix and dendrogram files
  --plot_trees           Enable generation of relationship trees (dendrograms)
```

## Output Formats

### Fingerprint (.fgr) Format
Each line contains tab-separated values:
```
<k-mer_sequence>\t<hash_value>\t<count>
```

### Similarity Matrix Formats
- `.jac` - Jaccard Index similarity matrix
- `.cos` - Cosine Similarity matrix

## Examples

1. Generate fingerprints for a sequence file:
```
./fgr -k 21 -t 8 -N 5000 sample.fasta
```

2. Calculate similarity between fingerprints:
```
python calculate_similarity.py -o comparison --plot_trees ./fingerprints/
```

## Requirements

- C compiler (GCC recommended) for fgr.c/fgr2.c
- Python 3.x for calculate_similarity.py
- Optional: scipy and matplotlib for dendrogram visualization
